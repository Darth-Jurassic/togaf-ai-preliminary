# Product Context

This repository is a reusable architecture process and metamodel reference. It
does not select a product, company, tenant, domain, deployment environment or
technology implementation for an adopting project.

Before model work, the adopting project records its purpose, stakeholders,
owning Location, baseline, boundaries and evidence in its own canonical model.
Distinguish the authority operating the project from external providers and
customer/tenant origins; do not infer ownership from a DNS or repository name.

Product or brand naming rules require an explicit preliminary naming decision
after stakeholder discussion. No namespace prefix, public hostname, package
identity, commercial agreement or production deployment is selected here.
